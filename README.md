 # whoop_sync
                                                                                                                                                                                                                                                                                                                                                                          
  Phase 1 data pipeline for Skin Intelligence. Pulls Whoop biometrics via the
  official v2 API and logs them to a single Excel file — one row per day —                                                                                                                                                                                                                                                                                                
  so that later phases can correlate biometrics with eczema flare-ups.                                                                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                                                                                                          
  ## What you get                                                                                                                                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                                                                                                                          
  `data/flavia_whoop_data.xlsx` with four sheets:
                                                                                                                                                                                                                                                                                                                                                                          
  - **daily_log** — one row per day, most recent at top. 20 biometric columns plus
    `first_loaded_at` (preserved on re-sync) and `last_updated_at` (bumped when                                                                                                                                                                                                                                                                                           
    Whoop sends new values, so the top-right cell shows "when was this row last                                                                                                                                                                                                                                                                                           
    touched").                                                                                                                                                                                                                                                                                                                                                            
  - **raw_sleep** — every sleep record, including naps and split sleeps.                                                                                                                                                                                                                                                                                                  
  - **raw_workouts** — every workout with strain, HR, calories.                                                                                                                                                                                                                                                                                                           
  - **metadata** — first sync / last sync / total days / missing dates / rate-limit snapshot.                                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                                                                                          
  Load it in pandas with zero cleanup:                                                                                                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                                                                                                          
  ```python       
  import pandas as pd                                                                                                                                                                                                                                                                                                                                                     
  df = pd.read_excel("data/flavia_whoop_data.xlsx", sheet_name="daily_log")
  ```                                                                                                                                                                                                                                                                                                                                                                     
  
  ## One-time setup                                                                                                                                                                                                                                                                                                                                                       
                  
  ### 1. Register a Whoop developer app
                                                                                                                                                                                                                                                                                                                                                                          
  1. Go to <https://developer.whoop.com/> and sign in with your Whoop account.
  2. Create a new app.                                                                                                                                                                                                                                                                                                                                                    
  3. For the redirect URI, register **exactly**: `http://localhost:8645/callback`                                                                                                                                                                                                                                                                                         
  4. Note the `client_id` and `client_secret`.                                                                                                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                                                                                                                                          
  ### 2. Install Python deps                                                                                                                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                                                                                                          
  Requires Python 3.11+.
                                                                                                                                                                                                                                                                                                                                                                          
  ```bash         
  cd whoop_sync
  python -m venv .venv
  source .venv/bin/activate                                                                                                                                                                                                                                                                                                                                               
  pip install -r requirements.txt
  ```                                                                                                                                                                                                                                                                                                                                                                     
                  
  ### 3. Configure credentials

  ```bash
  cp .env.example .env
  ```                                                                                                                                                                                                                                                                                                                                                                     
   
  Edit `.env` and paste in your `WHOOP_CLIENT_ID` and `WHOOP_CLIENT_SECRET`.                                                                                                                                                                                                                                                                                              
  Leave `WHOOP_REFRESH_TOKEN` blank — the script will populate it on first run.                                                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                                                                          
  ## Running                                                                                                                                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                                                                                                          
  ```bash         
  python sync_whoop.py
  ```                                                                                                                                                                                                                                                                                                                                                                     
   
  - **First run:** opens a browser for Whoop OAuth, saves the refresh token                                                                                                                                                                                                                                                                                               
    to `.env`, and pulls all available history (Whoop retains ~25 days on the                                                                                                                                                                                                                                                                                             
    free tier, longer on paid accounts — the script asks for up to 400 days and                                                                                                                                                                                                                                                                                           
    takes whatever the API returns).                                                                                                                                                                                                                                                                                                                                      
  - **Subsequent runs:** incremental. Pulls from (latest_date - 3 days) forward,                                                                                                                                                                                                                                                                                          
    so re-scored sleep/recovery is captured. Duplicate dates are merged in place.                                                                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                                                                                                                          
  Every run appends a line to `logs/sync_log.txt` with counts and the rate-limit snapshot.

  ## Whoop API notes (Phase 1 findings)
                                                                                                                                                                                                                                                                                                                                                                          
  - **API version:** v2. v1 was deprecated and webhooks migrated.
  - **Base URL:** `https://api.prod.whoop.com`; data endpoints nest under `/developer/v2/...`.                                                                                                                                                                                                                                                                            
  - **Scopes used:** `read:recovery read:cycles read:workout read:sleep read:profile read:body_measurement offline`.                                                                                                                                                                                                                                                      
    The `offline` scope is required to get a refresh token.                                                                                                                                                                                                                                                                                                               
  - **Refresh tokens rotate.** Every refresh invalidates the previous token and                                                                                                                                                                                                                                                                                           
    returns a new one — the script writes the new token back to `.env` so the                                                                                                                                                                                                                                                                                             
    next run works.                                                                                                                                                                                                                                                                                                                                                       
  - **Rate limits:** 100 req/min, 10,000 req/day. The client reads                                                                                                                                                                                                                                                                                                        
    `X-RateLimit-*` response headers and writes the latest snapshot to the                                                                                                                                                                                                                                                                                                
    metadata sheet. On 429, it honors `Retry-After` with exponential backoff.                                                                                                                                                                                                                                                                                             
  - **Pagination:** list endpoints return `{"records": [...], "next_token": "..."}` with a hard cap of 25 records per page.                                                                                                                                                                                                                                               
  - **Day boundary:** Whoop uses *cycles*, not calendar days. A cycle starts at                                                                                                                                                                                                                                                                                           
    your morning wake and ends at the next morning's wake. We use the cycle's                                                                                                                                                                                                                                                                                             
    `start` date (local) as the `date` column in daily_log.                                                                                                                                                                                                                                                                                                               
  - **Sleep selection:** a given day can have multiple sleep records (naps, split                                                                                                                                                                                                                                                                                         
    sleeps). daily_log uses the longest non-nap sleep whose `end` falls on the                                                                                                                                                                                                                                                                                            
    cycle date; naps are still captured in `raw_sleep`.                                                                                                                                                                                                                                                                                                                   
  - **Skin temp / SpO2:** only populated on Whoop 4.0 and later. Older units                                                                                                                                                                                                                                                                                              
    return null — those land as empty cells in the spreadsheet, no cleanup needed.                                                                                                                                                                                                                                                                                        
  - **Finalised scores:** Whoop sometimes rescores a night's sleep hours after                                                                                                                                                                                                                                                                                            
    it ends. The 3-day incremental overlap on each sync captures those updates.                                                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                                                                          
  ## Troubleshooting                                                                                                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                                                                          
  - **OAuth opens but hangs:** the redirect URI in your Whoop dev app must match
    `http://localhost:8645/callback` exactly. Port must be free.                                                                                                                                                                                                                                                                                                          
  - **"Token refresh failed":** clear `WHOOP_REFRESH_TOKEN` in `.env` and re-run                                                                                                                                                                                                                                                                                          
    to redo the OAuth flow.                                                                                                                                                                                                                                                                                                                                               
  - **Excel file won't open:** it's being held open by Excel itself — close the                                                                                                                                                                                                                                                                                           
    file before running the sync.
